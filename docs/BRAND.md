# HumanizerOS brand assets

The repository ships with reusable first-party visual assets:

- `assets/hero.svg` — README hero;
- `assets/terminal-demo.svg` — product walkthrough used in both READMEs;
- `assets/social-preview.png` — 1280×640 image for GitHub's social preview setting.

## Naming

Use `HumanizerOS` for the product, `humanizer-os` for the repository, distribution, CLI, and Agent Skill, and `humanizer_os` only for Python imports.

## Tagline

English: **The open platform for humanizing text.**

Russian: **Открытая платформа для очеловечивания текста.**

Supporting line: **Natural language. Preserved facts. Your voice.** / **Живой язык. Сохранённые факты. Ваш голос.**

## Asset policy

Keep the visual system language-neutral. Product screenshots may contain English or Russian, but the primary mark and hero must work for both audiences. Do not frame the product as an AI-detector bypass tool.
