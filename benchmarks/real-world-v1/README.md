# Real-World Benchmark v1

This directory turns provenance-tracked AI-generated samples into a reproducible HumanizerOS evaluation.

## Status

The benchmark is currently a **seed framework with one sample**. Its numbers verify the pipeline and prevent silent regression; they are not statistically representative. The v1 target is 30–50 samples across topics, genres, and generation models.

The first record comes from the MIT-licensed Human Detectors dataset. It uses a released `gpt-4o` sample labeled `AI-generated`, a HumanizerOS-authored rewrite, and explicit source notes. The paired human-written reference article is not copied into this repository.

## What it measures

For each sample, the runner records:

- source and rewrite word counts;
- findings before and after the rewrite;
- per-rule finding counts;
- Fact Guard status and protected-item count;
- regression checks declared in the manifest;
- provenance fields such as ground-truth label, model, and license.

The benchmark does not calculate an AI-authorship probability. Human annotations are retained as qualitative signals until the corpus has a stable annotation taxonomy.

## Run it

```bash
python scripts/benchmark_real_world.py
python scripts/benchmark_real_world.py --json
python scripts/benchmark_real_world.py --check
```

Regenerate committed results after an intentional engine change:

```bash
python scripts/benchmark_real_world.py --write
```

CI runs `--check`, so changed rules or fact extraction cannot silently invalidate the published result.

## Files

- [`manifest.jsonl`](manifest.jsonl) — one provenance and expectation record per sample;
- [`results.json`](results.json) — deterministic output generated by the current engine;
- [`../../examples/real-world-ai-source.md`](../../examples/real-world-ai-source.md) — provenance for the seed sample;
- [`../../examples/real-world-ai-before.md`](../../examples/real-world-ai-before.md) — released machine-generated source;
- [`../../examples/real-world-ai-after.md`](../../examples/real-world-ai-after.md) — HumanizerOS-guided rewrite.

## Adding a sample

A contribution needs:

1. permission to redistribute the machine-generated text;
2. an explicit ground-truth label and generation-model field when available;
3. a provenance file with source and license notes;
4. an independently authored rewrite;
5. human annotation signals when the source dataset provides them;
6. expected rule counts and Fact Guard values for regression;
7. no copied human reference article unless its license clearly permits redistribution.

The benchmark is an editorial and preservation test. It does not endorse factual claims found in the source material.
