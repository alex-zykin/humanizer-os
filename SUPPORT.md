# Support

Use GitHub Issues for reproducible bugs, false positives, and rule proposals. Do not paste confidential, personal, or copyrighted source text; reduce a report to the smallest safe example.

Security vulnerabilities belong in a private GitHub Security Advisory, as described in [SECURITY.md](SECURITY.md).

HumanizerOS is an open-source project. There is no guaranteed response time or private support channel in the 0.x series.
